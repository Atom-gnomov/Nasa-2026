# Огляд усіх сторінок після уніфікації інтерфейсу

Оновлено: 2026-11-14. Гілка: `yarylo/fullscreen-glass-ui`. Вимоги власника: постійний хедер; на «Місяці» і «Системі» full-screen WebGL + прозорі фіксовані бокові віджети + нижні інструменти; решта — аналітичне полотно. Розгортання однієї панелі згортає іншу й зменшує реальний canvas до 50 % ширини.

Документи: [концепт](fullscreen-workspace.md), [SVG-схеми](layout-wireframes.svg), [передача реалізації](implementation-guide.md).

## Система оформлення

- Візуальна тема: темний космічний фон `#0b1019` / `#0b0d12`, панелі темно-сині, текст світло-сірий, акцент `#f5b942`.
- Прозорі панелі на сценах (`--glass` ≈ 88 %), розмиття й тонкі рамки; аналітичні панелі трохи щільніші, щоб таблиці читалися.
- Однакова структура кожного віджета: верхній заголовок і кнопки керування, внутрішній незалежний скрол.
- Кнопки, select, input, slider, fieldset, таблиці, підказки й статуси отримують спільні стилі у `workspace.css`; старий `style.css` зберігає детальну геометрію графіків/спеціальних компонентів.
- Для таблиць — горизонтальне прокручування в рамці, зафіксований ряд заголовків, м'який hover і видимий keyboard focus.
- Порожній стан аналітичних результатів містить коротке пояснення; після появи таблиці пояснення приховується, якщо браузер підтримує `:has()`.
- На екранах до 760 px аналітичні області стають вертикальними; для дуже вузьких екранів expanded-віджет сцени займає весь viewport. На широких — 50/50.
- Дата і мова єдині для всіх вкладок; активна вкладка позначається `aria-current="page"`. Додано skip-link для клавіатурної навігації.

## Виявлені й виправлені проблеми

1. Функція заміру висоти хедера шукала `#site-header`, якого не було. ID додано; висота обчислюється через ResizeObserver і використовується всіма fixed-віджетами та 3D-сценами.
2. Вид з поверхні мав 3 незалежні фіксовані рядки інструментів з ризиком накладання. Їх переміщено до одного згортного `ui-surface-dock`, повернення до глобуса доступне навіть у згорнутому стані.
3. Сторінки «Вікно запуску», «План місії» і «Підбір» не мали послідовно оформлених центральних заголовків і стану до розрахунку. Узгоджено структуру заголовків.
4. Вбудований у сторінку «Місяць» старий «Підбір» уже відокремлено у власну аналітичну вкладку; його ID і API збережені. Результати точок передаються в глобус через спільний стан і sessionStorage.
5. Потенційне перекриття `[hidden]` авторськими `display:grid/flex` вирішується явним правилом `[hidden]` у `workspace.css`.

## Перевірки та статус

- Звірено всі HTML ID з літеральними зверненнями `getElementById` / `$(id)` у відповідних модулях. На «Системі» графік Сонця/Землі/DSN створює `workspace_ui.js` до старту `charts.js`, тому цих трьох ID немає в вихідному шаблоні — це очікувано.
- Чиста логіка normal/collapsed/expanded перевіряє взаємне виключення розгортання в `tests/js/test_workspace_ui.mjs`.
- Нові перевірки шаблонів у `tests/test_pages.py` покривають спільний хедер, активну вкладку, наявність сцени та відсутність глобуса на аналітичних сторінках.
- **Не було** повного browser QA, запуску Flask із DEM/Diviner, повного CI або перевірки WebGL у живому браузері в середовищі GitHub-конектора. Результат — інтегрований код у гілці, **не підтверджене production-злиття**.

## Залишковий чекліст для наступного виконавця

1. Запустити всі Python/Node тести з `design/implementation-guide.md`.
2. Перевірити справжній canvas resize (devtools `getBoundingClientRect`) у `expanded left/right`; коли один займає половину, інший має стати collapsed.
3. Перевірити 3D глобус, 2D-карту, полярний режим, поверхню, освітлення, температуру, графіки й метрики точки.
4. Перевірити «Систему» — масштаб, focus, DSN, симуляцію, графік і телеметрію після перенесення елементів.
5. Перевірити `/search`: повний пошук, таблицю, кнопку ШІ, перехід в Місяць і відновлення позначок.
6. Перевірити форми `/mission`, `/plan`, `/launch-window`, особливо вузькі таблиці й кнопки у form-віджеті.
7. Перевірити 1920×1080, 1366×768, 1024×768, 768×1024, 390×844, великі шрифти (zoom 200 %), без WebGL, клавіатуру, Firefox/Safari.
8. На основі browser QA скоригувати локальні media queries і висоту нижнього дока без зміни математичних моделей.

## Оновлення скляних віджетів (2026-11-14)

В усіх шести вкладках використовується один скляний матеріал `--glass-bg` для бокових панелей і центру результатів. У «Місяці» й «Системі» нижній док обмежений 840px завширшки та 132px заввишки. Для вузьких екранів — повна доступна ширина з відступами. Деталі див. [responsive-layout.md](responsive-layout.md).
