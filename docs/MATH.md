## 1. Шкали часу

- Користувач вводить **UTC**. Ефемериди працюють у **TDB** (барицентричний динамічний час).
- Перехід: `TT = TAI + 32,184 с`, `TAI = UTC + leap seconds` (зараз 37 с), `TDB ≈ TT` з точністю до 1,7 мс.
- Для дат у майбутньому нові секунди координації невідомі. Похибка — кілька секунд, це нехтовно мало: Сонце за 10 с зсувається на 0,0014°.
- У Python усе робить `skyfield` (`load.timescale(builtin=True)`).
- **«Земні години»** — звичайні години UTC. Корисні сталі:
  - синодичний місяць (лунна доба, від сходу до сходу Сонця) = 29,5306 доби = **708,7 год**;
  - сидеричний місяць = 27,3217 доби;
  - драконічний рік (період «сезонів» освітлення полюса) = 346,62 доби;
  - нутаційний цикл (повторення умов освітлення) = 18,6 року.

## 2. Ефемериди

- **Джерело:** JPL DE440 (`de440.bsp`): положення Сонця, Землі й Місяця, покриття 1550–2650.
  - У Python ядро доступне пакетом `naif-de440` з PyPI (114 МБ). Це зручно, бо сайти NASA бувають недоступні з серверів.
  - Для легшого варіанта — `de440s.bsp` (1849–2150, ~32 МБ).
- **Вектор на Сонце з центру Місяця:** `moon.at(t).observe(sun)` — з поправкою на час проходження світла (~8,3 хв). Без поправки похибка ~0,07°.
- **Вектор на Землю:** `earth − moon` (геометричний). Світло йде 1,3 с, поправка нехтовна.
- **Топоцентричність важлива для Землі:** радіус Місяця 1737 км із відстані 384 000 км дає паралакс до **0,26°**. Тому вектор на Землю беремо від точки на поверхні, а не від центру Місяця. Для Сонця паралакс 0,0007° — нехтуємо.

## 3. Орієнтація Місяця (тіло → небо)

Щоб перевести вектор з інерціальної системи (ICRF) у систему, прив'язану до поверхні Місяця, потрібна орієнтація Місяця на момент `t`.

**Дві системи координат Місяця:**
- **MOON_ME** (Mean Earth / Polar axis) — у ній задані всі карти та DEM LOLA. **Працюємо в ній.**
- **MOON_PA** (Principal Axis) — система головних осей інерції, у ній інтегрується фізична лібрація в DE440. Відрізняється від ME на ~0,02° (~875 м на поверхні).

**Варіанти реалізації:**
1. **Продакшн (рекомендовано):** бінарний PCK `moon_pa_de440_200625.bpc` + кадр `moon_de440_220930.tf` (поворот PA → ME). Точність — метри. У skyfield: `load_file(pck)`, `PlanetaryConstants`, `pc.build_frame_named('MOON_ME_DE440_ME421')`. ⚠️ Файли доступні лише з naif.jpl.nasa.gov — завантажити вручну й покласти в `data_cache/`.
2. **Запасний (використано в скрипті):** аналітична модель **IAU WGCCRE 2015** (Archinal et al., 2018). Точність ~0,01° (сотні метрів), для наших метрик (0,1°) достатньо, зовнішні файли не потрібні.

**Модель IAU** (`d` — доби TDB від J2000, `T = d / 36525`):

```
α0 = 269,9949 + 0,0031·T − 3,8787·sin E1 − 0,1204·sin E2 + 0,0700·sin E3 − 0,0172·sin E4
     + 0,0072·sin E6 − 0,0052·sin E10 + 0,0043·sin E13
δ0 = 66,5392 + 0,0130·T + 1,5419·cos E1 + 0,0239·cos E2 − 0,0278·cos E3 + 0,0068·cos E4
     − 0,0029·cos E6 + 0,0009·cos E7 + 0,0008·cos E10 − 0,0009·cos E13
W  = 38,3213 + 13,17635815·d − 1,4·10⁻¹²·d² + 3,5610·sin E1 + 0,1208·sin E2 − 0,0642·sin E3
     + 0,0158·sin E4 + 0,0252·sin E5 − 0,0066·sin E6 − 0,0047·sin E7 − 0,0046·sin E8
     + 0,0028·sin E9 + 0,0052·sin E10 + 0,0040·sin E11 + 0,0019·sin E12 − 0,0044·sin E13
```

Аргументи E1…E13 (градуси) — у функції `iau_moon_angles()` скрипта.

**Матриця повороту ICRF → тіло Місяця:**

```
M = Rz(W) · Rx(90° − δ0) · Rz(90° + α0)
r_тіло = M · r_ICRF
```

де `Rz(θ) = [[cos θ, sin θ, 0], [−sin θ, cos θ, 0], [0, 0, 1]]`, `Rx` — аналогічно навколо осі X.

Модель перевірено ✅: вона дає правильні діапазони лібрації та широти підсонячної точки (розділ 0).

## 4. Координати точки на Місяці

- **Селенографічні координати:** широта φ (південь — від'ємна), довгота λ на схід (−180…180 або 0…360).
- **Опорна сфера:** R = **1737,4 км** (IAU; LOLA теж використовує сферу).
- **Декартові координати в MOON_ME:**

```
r = (R + h) · (cos φ cos λ,  cos φ sin λ,  sin φ)
```

де `h` — висота рельєфу з DEM відносно сфери плюс висота щогли/панелі над ґрунтом.

**Полярна стереографічна проєкція** (DEM LOLA для полюса в ній). Для південного полюса:

```
ρ = 2R · tan(π/4 + φ/2)       (φ < 0, на полюсі ρ = 0)
x = ρ · sin λ,   y = ρ · cos λ
Обернено: ρ = √(x² + y²),  φ = −(π/2 − 2·atan(ρ / 2R)),  λ = atan2(x, y)
```

⚠️ Знаки осей у різних продуктах відрізняються — звірити з метаданими GeoTIFF (WKT/PROJ-рядок) і перетворювати через `pyproj`, а не вручну.

## 5. Топоцентрична система й азимут/кут місця

Для точки (φ, λ) — локальні орти **East, North, Up**:

```
U = (cos φ cos λ,  cos φ sin λ,  sin φ)
E = (−sin λ,  cos λ,  0)
N = U × E
```

Для вектора на об'єкт `d̂` (одиничний, від точки на поверхні):

```
кут місця   el = asin(U · d̂)
азимут      az = atan2(E · d̂,  N · d̂)        (від півночі за годинниковою стрілкою)
```

**Особливість полюса:** у точці φ = −90° напрямок «на північ» не визначений — усі напрямки ведуть на північ. Домовленість для застосунку:
- на самому полюсі «північ» = напрямок на меридіан λ (за замовчуванням 0°), так званий **grid north**;
- у документації й інтерфейсі писати, від чого відлічується азимут;
- маски горизонту зберігати в тій самій домовленості.

## 6. Горизонт

### 6.1. Геометричний горизонт (гладка сфера)
Атмосфери немає, **рефракції немає** — промінь прямий. Для спостерігача на висоті `h` над ідеальною сферою горизонт опускається:

```
пониження горизонту  dip = acos(R / (R + h)) ≈ √(2h / R)
дальність горизонту  D = √(2·R·h)
```

| Висота | Пониження | Дальність |
|---|---|---|
| 1 м | 0,061° | 1,9 км |
| 2 м | 0,087° | 2,6 км |
| 10 м | 0,194° | 5,9 км |
| 100 м | 0,615° | 18,6 км |

Висновок: щогла 10 м «опускає» горизонт на 0,2°, а це помітна частка діапазону ±1,6° руху Сонця на полюсі. Висоту панелі/антени треба давати як параметр.

### 6.2. Маска горизонту з рельєфу (М6)
**Маска** — для кожного азимута (крок 0,5–1°) максимальний кут піднесення рельєфу.

Алгоритм для точки P (висота `h_P` з DEM + висота щогли):
1. Для кожного азимута `az` йдемо вздовж променя кроками `s` (від 1–2 пікселів DEM, крок росте з відстанню).
2. У точці на відстані `d` з висотою рельєфу `h_T` кут піднесення з урахуванням кривизни:

```
α(d) = atan( (h_T − h_P − d² / (2R)) / d )
```

3. Маска `mask(az) = max по d від α(d)`.
4. Максимальна дальність — до **150–200 км**: на полюсі далекі масиви (Малаперт, Лейбніц Бета) закривають Сонце, хоча до них сотні кілометрів.

Точніший варіант — рахувати у векторах: `α = asin(U_P · (r_T − r_P) / |r_T − r_P|)`. Він не потребує наближення малих кутів.

Обсяг: DEM 20 м/піксель, 720 азимутів × ~5000 кроків = 3,6 млн вибірок на точку — секунди на numpy. Для сітки підбору локацій (друга черга) — передрозрахунок або GPU, грубіший DEM для далеких відстаней.

**Готові карти для перевірки:** PGDA Lunar Polar Illumination (Mazarico et al., 2011) — середня освітленість полюсів. Наші результати для тих самих точок мають збігатися з ними в межах кількох відсотків.

### 6.3. Частка диска над горизонтом
Сонце — диск радіусом r ≈ 0,267°. Нехай `k = (el − mask(az)) / r`, обмежене до [−1, 1]. Частка площі диска над горизонтом (сегмент круга):

```
f = 1 − (acos(k) − k·√(1 − k²)) / π
```

Перевірка ✅: k = −1 → 0; k = 0 → 0,5; k = 0,5 → 0,804; k = 1 → 1.

✅ Реалізовано в `app/core/horizon.py` (`disk_fraction`). Лінійне наближення `(k + 1) / 2`, яке було раніше, помилялося до 0,058 частки диска (≈ 6 %).

Для Землі (радіус ~0,95°) та сама формула дає частку диска. **Для зв'язку важлива не частка диска, а видимість конкретної станції DSN** — див. розділ 9.

### 6.4. Маска з мозаїки DEM LOLA (реалізовано, PR #12)
Висота в точці променя береться з **найдетальнішого** продукту, що її покриває: LDEM_875S_20M → LDEM_80S_80M → LDEM_64 → LDEM_16 (`core/dem.mosaic_height_fn`). Піксель ↔ lat/lon — за формулами міток PDS: циліндрична — `dsmap.cat` (центр пікселя з урахуванням пів пікселя), полярна стереографічна — `dsmap_polar.cat` (редакція 2022: на півдні 0° угору, 90° сх. праворуч). Перевірено ✅: полярний і глобальний продукти на перекритті — кореляція 0,999 (дзеркальне розміщення — 0,39).
Для тіней на глобусі (М12) маска передраховується в атлас: 24 азимути на піксель полярної ділянки, промені до 150 км з урахуванням кривини.

### 6.5. Нахил і експозиція схилу
```
d = 2 · крок DEM;  точки на великому колі: Q = cos(d/R)·P ± sin(d/R)·e,  ± sin(d/R)·n
g_x = (h(+e) − h(−e)) / 2d,  g_y = (h(+n) − h(−n)) / 2d
нахил = atan(√(g_x² + g_y²)),  експозиція = atan2(−g_x, −g_y)  (куди схил іде вниз, від півночі)
```
Через вектори — тому працює й на самому полюсі.

## 7. Схід, захід і «час до заходу»

Функція видимості: `g(t) = el(t) − mask(az(t))`. Схід — `g` переходить через 0 знизу вгору, захід — згори вниз. Для Сонця беремо верхній край диска (`el + r`) або повне зникнення (`el − r`), залежно від метрики.

Алгоритм:
1. Крок вибірки: Сонце рухається по азимуту ~0,5°/год, тому крок **10–20 хв** (маска між азимутами змінюється різко). Для Землі вистачає **1 год**.
2. Знайти інтервали, де `g` змінює знак.
3. Уточнити бісекцією або методом Брента до 1 хв.
4. «Час до заходу» = момент найближчого заходу − поточний момент, у земних годинах.

**Пастка полюса:** Сонце ковзає вздовж зубчастого горизонту, і за одну лунну добу буває кілька сходів і заходів (визирає між пагорбами). Тому шукаємо **всі** перетини, а в інтерфейсі показуємо найближчий захід і загальну тривалість світла.

## 8. Години Сонця й зв'язку за період

Для діапазону дат [t₁, t₂] з кроком Δt:

```
години Сонця  = Σ f_сонце(tᵢ) · Δt          (f — частка диска, розділ 6.3)
години зв'язку = Σ [станція видна](tᵢ) · Δt
частка часу   = години / (t₂ − t₁)
```

- Крок Δt = 1 год дає похибку < 1 % на періоді від місяця. Для точних меж беремо інтервали з розділу 7.
- **Повзунок «від 0 до максимуму»:** максимум = довжина періоду в годинах. Реальний максимум для полюса нижчий: навіть найкращі піки освітлені ~80–90 % часу за рік 📚 (Mazarico et al., 2011). Тривалий «вічний день» не існує.
- **Сезони:** вісь Місяця нахилена до екліптики на 1,54°, тому висота Сонця на полюсі змінюється з періодом 346,6 доби (драконічний рік). Ті самі місяці в різні роки не однакові, а повний цикл умов повторюється за 18,6 року. Для «десятків років уперед» це важливо.

## 9. Зв'язок і DSN (М8)

### 9.1. Затримка сигналу
```
затримка = |r_станція − r_точка_на_Місяці| / c,   c = 299 792,458 км/с
```
Діапазон 1,19…1,36 с в один бік ✅. Ефект Шапіро та атмосфера — мікросекунди, нехтуємо.

### 9.2. Умова прямого зв'язку
Зв'язок є, коли **одночасно**:
1. **Станція DSN видна з точки на Місяці:** вектор від точки на Місяці до станції на Землі (не до центру Землі!) вище маски горизонту точки. Станція може бути до ~0,95° убік від центру диска Землі.
2. **Місяць видний зі станції:** кут місця Місяця над горизонтом станції ≥ мінімального кута антени (зазвичай 6–10°; ⚠️ звірити з DSN 810-005, модуль 301).
3. *(Друга черга)* Точка на Землі, куди потрібен зв'язок, з'єднана зі станцією наземною мережею — вважаємо, що завжди.

Положення станцій: `skyfield.api.wgs84.latlon(lat, lon, h)` — skyfield сам враховує обертання Землі.

**Перевірка ✅ (2027, кут місця > 10°):** кожна станція бачить Місяць 40–42 % часу, хоча б одна — **98 %** часу. Значить, бувають короткі «дірки» — їх треба показувати.

**Рекомендація станції** = станція з найбільшим кутом місця Місяця, серед тих, для яких виконані умови 1 і 2.

## 10. Енергія сонячних панелей

```
S = 1361 · (1 а.о. / r_Сонце)²   Вт/м²              (1310…1415 біля Місяця ✅)
P = η · A · S · cos(θ) · f
```

- `η` — ККД панелі (0,28–0,32 для космічних), `A` — площа, `f` — частка диска над горизонтом (6.3), `θ` — кут між нормаллю панелі й напрямком на Сонце.
- **Вертикальна панель, що повертається за Сонцем** (типово для полюса): `cos θ = cos(el)` ≈ 1. Приклад: 1 м², η = 0,30 → **~408 Вт**.
- **Горизонтальна панель:** `cos θ = sin(el)`. При el = 1,5° → **~11 Вт** з того ж 1 м². Тому на полюсі панелі ставлять вертикально.
- Енергія за період = Σ P(tᵢ)·Δt (Вт·год). Ще корисна метрика — **найдовша ніч** (найдовший інтервал без Сонця): від неї залежить ємність акумуляторів.

## 11. Температура (друга черга)

Наближення радіаційної рівноваги без теплової інерції:

```
T = ( (1 − A) · S · cos i  /  (ε · σ) )^(1/4)
```

`A` ≈ 0,12 (альбедо), `ε` ≈ 0,95, `σ` = 5,670·10⁻⁸ Вт/(м²·К⁴), `i` — кут падіння променів.

| Ситуація | cos i | T |
|---|---|---|
| Екватор, полудень | 1 | ~386 K (+113 °C) |
| Полюс, рівна поверхня, el = 1,5° | 0,026 | ~155 K (−118 °C) |
| Полюс, схил до Сонця | ~1 | до ~380 K |
| Постійно затінені кратери | 0 | 25–70 K 📚 (Diviner, Paige et al., 2010) |

Обмеження: модель не враховує теплову інерцію реголіту, тож нічне охолодження та підігрів від сусідніх освітлених схилів не видно. Для оцінки краще брати виміряні карти Diviner (див. RESOURCES.md, розділ 3) і цю формулу лише для інтерполяції.

### 11.1. Виміряна температура LRO Diviner (реалізовано, PR #12)
Замість формули вище показуємо **вимірювання**. GCP: болометрична T у комірках 0,5° за місцевим сонячним часом (бін 15 хв).
```
LT = 12 год + (λ − λ_підсонячна) / 15°   (mod 24)
```
λ_підсонячна — з DE440 + IAU 2015 на дату. Прогалини в бінах до 2 год заповнюємо лінійно (по колу доби), довші — «немає даних».
Перевірено ✅ (Williams et al. 2017): екватор, полудень — 390,5 K (≈ 390); перед світанком — 94,8 K (≈ 95).

PRP (південь, ~0,5 км): річні середня (на глибині 2 см) і максимальна (на поверхні) T, глибина стабільного льоду. Код −1 у колонці глибини мітка не описує; у даних він лише там, де T_max = 45…101 K (холодніше за клас «0» зі 101…124 K) — трактуємо як «лід на поверхні». Поріг підповерхневого льоду — **річна середня ~110 K** (нижче — 100 % комірок, 120–130 K — 7 %, вище 130 K — ~0), що відповідає Paige et al. 2010. Орієнтацію PRP перевірено за висотами трикутників: кореляція з LOLA 0,9996, медіана різниці 28 м.

## 12. Радіація (друга черга)

- Фон на поверхні — галактичні космічні промені (ГКП) + рідкісні сонячні протонні події.
- Виміряно на Chang'e 4 (LND): **~1369 мкЗв/добу** еквівалентної дози, поглинена ~13 мкГр/год 📚 (Zhang et al., 2020, *Science Advances*). Це у ~200–300 разів більше, ніж на поверхні Землі.
- **Рельєф екранує:** Місяць уже закриває половину неба (2π ср). Стінки кратера закривають ще частину. Оцінка — **коефіцієнт видимості неба** з маски горизонту:

```
Ω = ∫₀^{2π} (1 − sin(mask(az))) d(az)          (тілесний кут відкритого неба)
доза ≈ D_відкрита · Ω / (2π)
```

На рівнині Ω/(2π) = 1. На дні кратера з маскою 15° по колу Ω/(2π) = 1 − sin 15° ≈ 0,74, тобто доза менша на ~26 %. Наближено: ГКП приходять ізотропно; вторинне випромінювання від ґрунту не враховано ⚠️.

## 13. Запуски з Землі (друга черга)

- **Прибавка швидкості від обертання Землі:** `v = 465,1 · cos(широта)` м/с.

| Космодром | Широта | Прибавка |
|---|---|---|
| Екватор (морська платформа) | 0° | 465 м/с |
| Куру | 5,2° | 463 м/с |
| Шрихарикота | 13,7° | 452 м/с |
| Канаверал | 28,5° | 409 м/с |
| Байконур | 45,9° | 324 м/с |
| Восточний | 51,9° | 287 м/с |

- **Нахил орбіти:** не менший за широту старту (`i ≥ |φ|`). Площина перелітної орбіти має пройти через Місяць у момент прибуття, тобто `i ≥ |δ_Місяця|`. Схилення Місяця коливається від ±18,3° до ±28,6° із циклом 18,6 року ✅.
- **Зміна площини** (якщо потрібна): `Δv = 2·v·sin(Δi / 2)` — дуже дорого, на НОО ~135 м/с за кожен градус.
- **Траєкторії:**
  - **пряма:** ~3–5 діб, імпульс розгону з НОО ~3,1–3,2 км/с 📚;
  - **найекономніша (низькоенергетична, через точку Лагранжа L1 системи Сонце–Земля):** ~3–4 місяці, економія на гальмуванні біля Місяця ~100–200 м/с ⚠️ (приклад — CAPSTONE, ~4 місяці).
- **Стартове вікно:** дати, коли для вибраної траєкторії Місяць у потрібній точці орбіти, а місце посадки освітлене в момент прибуття (на полюсі — щоб посадка припала на початок довгого світлого періоду).

## 14. Оцінка та оптимізація (друга черга)

**Нормалізація** кожної метрики до [0, 1]:
- «більше — краще» (години Сонця, зв'язку): `s = (x − x_min) / (x_max − x_min)`;
- «менше — краще» (вартість, ризик, доза, час польоту): `s = (x_max − x) / (x_max − x_min)`;
- або поріг користувача: `s = 1`, якщо вимогу виконано, інакше пропорційно.

**Ваги з порядку блоків** (перетягування) — метод Rank Order Centroid. Для `n` факторів фактор на місці `i`:

```
w_i = (1/n) · Σ_{k=i}^{n} 1/k
```

Для n = 4: 0,521 · 0,271 · 0,146 · 0,063. Користувач лише впорядковує блоки, а ваги отримуються автоматично й у сумі дають 1.

**Загальний бал і «оцінка у %» у вікні запуску:** `score = 100 · Σ wᵢ·sᵢ`.

**Режим «потрібно все» (мін-макс):**
- максимізуємо найгірший фактор: `score = 100 · min_i sᵢ`;
- **фронт Парето:** варіант A домінує B, якщо A не гірший за всіма факторами й кращий хоча б за одним. Показуємо лише недоміновані варіанти.

## 15. Бюджет точності

| Джерело похибки | Величина | Вплив |
|---|---|---|
| Модель орієнтації IAU замість PCK DE440 | ~0,01° | нехтовний |
| Ігнорування leap seconds у майбутньому | ~0,001° | нехтовний |
| Без поправки на час світла для Сонця | 0,07° | **враховувати** |
| Без топоцентричного паралаксу Землі | до 0,26° | **враховувати** |
| Лінійна частка диска замість сегмента | до 0,058 частки | **виправити** |
| Без рельєфу (гладка сфера) | маска до 5–10° | **критично** для полюса |
| Роздільність DEM 20 м проти 5 м | ~0,1° на близьких схилах | прийнятно для MVP |
| Висота щогли 0 проти 2–10 м | 0,09–0,19° | давати параметром |

**Цільова точність MVP:** кут місця ≤ 0,1°, моменти сходу/заходу ≤ 15 хв (для Землі на полюсі — ≤ 1 год через повільний рух).

## 17. Оскулюючі орбіти й фаза Місяця (реалізовано, PR #12)
Еліпс із вектора стану (r, v) відносно центрального тіла, μ = GM₁ + GM₂ (DE440):
```
h = r × v;   e = ((v² − μ/r)·r − (r·v)·v) / μ;   a = 1 / (2/r − v²/μ);   T = 2π·√(a³/μ)
r(ν) = a(1 − e²) / (1 + e·cos ν)
```
Еліпс замкнений і проходить через тіло; справжній шлях відходить через збурення. Перевірено ✅ (2026-11-13, 2027-07-01):

| Орбіта | a | e | нахил до екліптики | період | справжній шлях від еліпса |
|---|---|---|---|---|---|
| Барицентр Земля–Місяць навколо Сонця | 0,99999 а.о. | 0,0167 | 0,004° | 365,25 д | ≤ 7 500 км за рік (0,005 %) |
| Місяць навколо Землі | 383–386 тис. км | 0,05–0,07 | 5,0–5,2° | 27,2 д | ≤ 9 800 км за місяць (до 2,6 %, головно збурення від Сонця) |

Фаза: φ = кут між напрямками з Місяця на Сонце й на Землю; освітлена частка диска k = (1 + cos φ) / 2.
