# Orbital Glass — дизайн-система Lunar Site Explorer

**Джерело:** новий візуальний референс користувача (космічний центр керування з супутниками, 14 листопада 2026). Стилістика — глибокий чорний космос, скляні панелі з відбиттями, срібні тонкі контури, малі світлові акценти, компактна типографіка й «рідке скло», подібне за прийомами до iOS.

## Де працювати

- \`app/static/css/orbital-glass.css\` — нова **єдина презентаційна тема**, підключена останньою у \`app/templates/base.html\`.
- \`app/static/css/workspace.css\` — **геометрія**: повноекранна карта, 50/50, автоадаптація ширини, скрол хедера, розташування бокових віджетів, розміри нижнього дока.
- \`app/static/js/workspace_ui.js\`, \`workspace_state.js\` — поведінка віджетів, DOM і калькуляція висоти дока. **Тема їх не змінює**.
- Усі шість вкладок ділять цю тему: Місяць і Система з повноекранними сценами; Підбір / Місія / План місії / Вікно запуску без карти.

## Токени і стилі

\`--og-card\` — прозорий подвійний градієнт, тепло-сіре графітове скло із легким верхнім відбиттям; \`--og-rim\` — градієнтна 1px рамка з підсвіченим верхнім краєм; \`--og-shadow\` — м'яка глибока зовнішня тінь та внутрішня світлова лінія; \`--og-highlight\` — блиск заголовків; \`--og-button\` — внутрішні скляні кнопки.

- \`backdrop-filter: blur(27px) saturate(150%) brightness(1.08)\`, fallback у непрозорий графіт при недоступності.
- Палітра: фон \`#03070c\`, текст \`#edf4fa\`, метадані сріблясто-сірі, операційні активні контроли світло-блакитні / білі. Бурштиновий \`#e5ad55\` для попереджень, м'ятний для успішного статусу.
- Жовтий/помаранчевий колір WebGL міток, розрахункових графіків і наукових шарів **не змінений темою**.
- Кожен активний перемикач — сріблясто-скляна капсула, не суцільна жовта кнопка.
- Підтримуються \`prefers-reduced-transparency\`, \`prefers-reduced-motion\`, відсутність \`backdrop-filter\`.

## Acceptance check

1. На \`/moon\` та \`/system\` перевірити прозорість віджетів поверх 3D карти, читабельність тексту і контури на чорному тлі; не закривати нижній док.
2. На \`/search\`, \`/mission\`, \`/plan\`, \`/launch-window\` перевірити лівий скляний конфігуратор і той самий матеріал центральних результатів; справа ШІ лише для Підбору.
3. Перевірити всі \`normal/collapsed/expanded\`, 50/50 реального canvas, адаптивний однорядковий хедер, горизонтальний скрол налаштувань, дати.
4. На 390 / 1024 / 1440 / 1920 px перевірити видимість при zoom 200%, blur fallback, keyboard focus і контраст.
5. Запустити тести Python і Node зі старого \`design/implementation-guide.md\`. Окремо потрібна візуальна перевірка браузером: статичний CSS не гарантує відповідності референсу на всіх системах.

Зміни тільки у \`yarylo/fullscreen-glass-ui\`; \`main\` не змінювати без дозволу.

## Шар Cosmos (14 листопада 2026)

`app/static/css/cosmos.css` — космічний шар поверх Orbital Glass, підключений останнім у `base.html`: палітра індиго + ціан, зоряне тло з туманністю й повільним дрейфом (вимикається `prefers-reduced-motion`), моноширинні цифри телеметрії, заголовки панелей капсом зі світловим маркером. Кольори наукових шарів не змінені: `--accent` перевизначено локально, `:root` не чіпали. 3D-сцени (Three.js) лишаються на чорному тлі.
