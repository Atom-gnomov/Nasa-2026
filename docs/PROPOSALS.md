# Пропозиції та покращення

Сюди кожен (людина чи агент) може дописати ідею щодо продукту, дизайну чи документації.
Невеликі ідеї щодо конкретного модуля — у підрозділ «Пропозиції» відповідного модуля в [MODULES.md](MODULES.md).

## Як додати пропозицію
1. Додайте новий розділ **в кінець** файлу за шаблоном нижче. Чужі розділи не редагуйте — коментуйте в PR.
2. Статус змінює команда після обговорення.
3. Прийняту пропозицію переносимо у [VISION.md](VISION.md) (журнал рішень) або [MODULES.md](MODULES.md).

**Статуси:** 💡 нова · 💬 обговорюється · ✅ прийнята · ❌ відхилена · ⏸ відкладена

### Шаблон
```markdown
## П-<номер>. <Коротка назва>
- **Автор / дата:** …
- **Статус:** 💡 нова
- **Стосується:** VISION / MODULES (М…) / RESOURCES / UX / інше
- **Проблема:** що зараз не так або чого бракує
- **Пропозиція:** що зробити
- **Чому це корисно:** для кого і як
- **Вартість / ризики:** скільки роботи, що може зламатися
```
