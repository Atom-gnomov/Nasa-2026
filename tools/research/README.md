# tools/research/ — дослідницькі скрипти

Скрипти для перевірки математики з [docs/MATH.md](../../docs/MATH.md). Їх залежності не входять у `requirements.txt` застосунку.

```bash
pip install skyfield numpy naif-de440   # naif-de440 — ефемериди DE440, ~114 МБ
python tools/research/lunar_geometry.py
```

- `lunar_geometry.py` — положення Сонця й Землі з точки на Місяці (модель орієнтації IAU 2015), лібрація, затримка сигналу, пониження горизонту, видимість Місяця зі станцій DSN, схилення Місяця, прибавка швидкості від обертання Землі. Виводить контрольні числа для розділу 0 у MATH.md.
